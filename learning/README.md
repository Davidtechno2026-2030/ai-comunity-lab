# Centro de aprendizaje AI Community Lab

Bienvenido al centro educativo de AI Community Lab.

Aquí aprenderemos programación, inteligencia artificial y desarrollo tecnológico desde cero.

## Módulos

1. Fundamentos de programación.
2. Python desde cero.
3. HTML, CSS y JavaScript.
4. Fundamentos de inteligencia artificial.
5. Machine Learning y modelos LLM.

## Metodología

- Explicaciones desde cero.
- Ejemplos prácticos.
- Ejercicios progresivos.
- Pequeños proyectos.
- Documentación de los avances.

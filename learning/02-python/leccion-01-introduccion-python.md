# Lección 01 - Introducción a Python y su sintaxis

## 1. ¿Qué es Python?

Python es un lenguaje de programación utilizado para desarrollar aplicaciones, automatizar tareas, analizar datos y crear herramientas de inteligencia artificial.

## 2. ¿Qué es la sintaxis?

La sintaxis es el conjunto de reglas que debemos seguir para escribir código correctamente.

## 3. La función print()

La función print() permite mostrar información en pantalla.

Ejemplo:

    print("Hola, mundo")

## 4. Mostrar varios mensajes

Podemos utilizar varias instrucciones print() dentro de un programa.

Ejemplo:

    print("Bienvenido a Python")
    print("Estamos aprendiendo programación")
    print("AI Community Lab")

## 5. Comentarios

Los comentarios permiten añadir explicaciones al código. Python no los ejecuta.

Ejemplo:

    # Este es un comentario
    print("Hola")

## 6. Reglas básicas

- Las instrucciones deben escribirse respetando la sintaxis de Python.
- Los textos se escriben entre comillas.
- Los comentarios comienzan con #.
- La indentación organiza los bloques de código.

## Resumen

Python es un lenguaje versátil y legible. Su sintaxis permite escribir programas de forma clara y organizada.

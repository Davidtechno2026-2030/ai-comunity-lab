# Lección 02 - Tipos de datos y conversiones

## 1. ¿Qué son los tipos de datos?

Los tipos de datos indican qué clase de información estamos utilizando en un programa.

Python dispone de diferentes tipos de datos.

## 2. Cadenas de texto (str)

Se utilizan para almacenar textos.

Ejemplo:

    nombre = "David"
    print(nombre)

## 3. Números enteros (int)

Se utilizan para almacenar números sin decimales.

Ejemplo:

    edad = 16
    print(edad)

## 4. Números decimales (float)

Se utilizan para almacenar números con decimales.

Ejemplo:

    precio = 12.50
    print(precio)

## 5. Valores booleanos (bool)

Representan dos estados:

- True: verdadero.
- False: falso.

Ejemplo:

    proyecto_activo = True
    print(proyecto_activo)

## 6. Comprobar el tipo de dato

La función type() permite conocer el tipo de una variable.

Ejemplo:

    nombre = "AI Community Lab"
    print(type(nombre))

## 7. Conversiones de datos

Python permite convertir datos utilizando funciones como:

- str(): convierte un valor en texto.
- int(): convierte un valor en entero.
- float(): convierte un valor en decimal.

Ejemplo:

    numero = "25"
    numero_convertido = int(numero)
    print(numero_convertido)

## Resumen

Los tipos de datos permiten organizar la información de un programa.

Las conversiones permiten transformar un dato de un tipo a otro.

# Ejercicio 10 - Módulos e importaciones

## 1. Importar módulos

Se utilizó `import math` para calcular raíces cuadradas.

## 2. Importar funciones concretas

Se utilizó `from math import sqrt` para importar directamente una función.

## 3. Utilizar alias

Se utilizó `import random as azar` para asignar un nombre alternativo al módulo.

## 4. Trabajar con fechas

Se utilizó el módulo `datetime` para consultar la fecha y hora actuales.

## 5. Crear módulos propios

Se creó el archivo `operaciones.py` con dos funciones:

- `sumar(a, b)`
- `multiplicar(a, b)`

## 6. Importar módulos propios

Se importó `operaciones` y se ejecutaron sus funciones desde otro programa.

## 7. Aplicación práctica

Se creó una pequeña calculadora para AI Community Lab utilizando el módulo propio.

## Competencias adquiridas

- Importar módulos estándar de Python.
- Importar funciones concretas.
- Utilizar alias.
- Consultar fechas y horas.
- Crear módulos propios.

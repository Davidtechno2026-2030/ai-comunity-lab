# Ejercicio 04 - Listas y tuplas

## 1. Crear una lista

    lenguajes = ["Python", "Java", "JavaScript"]
    print(lenguajes)

## 2. Acceder a los elementos

    print(lenguajes[0])
    print(lenguajes[1])
    print(lenguajes[2])

## 3. Modificar una lista

    lenguajes[1] = "C++"
    print(lenguajes)

## 4. Añadir elementos

    lenguajes.append("Java")
    print(lenguajes)

## 5. Eliminar elementos

    lenguajes.remove("C++")
    print(lenguajes)

## 6. Crear una tupla

    coordenadas = (10, 20, 30)
    print(coordenadas)

## 7. Identificar los tipos de datos

    print(type(lenguajes))
    print(type(coordenadas))

## Conclusión

Las listas permiten almacenar y modificar varios elementos.

Las tuplas permiten almacenar varios elementos, pero no se pueden modificar después de crearlas.

# Ejercicio 03 - Variables y tipos de datos

## Objetivo
Aprender a guardar información y utilizar variables en Python.

## Actividad 1 - Crear variables

Crea cuatro variables:

- producto: un texto.
- precio: un número entero.
- unidades: un número entero.
- disponible: un valor True o False.

## Actividad 2 - Realizar una operación

Calcula el precio total multiplicando el precio por las unidades.

## Actividad 3 - Mostrar resultados

Utiliza print() para mostrar:

- Nombre del producto.
- Precio.
- Unidades.
- Precio total.
- Disponibilidad.

## Aprendizaje

Las variables permiten almacenar datos y utilizarlos para realizar operaciones.

# Ejercicio 06 - Funciones

## Objetivo
Aprender a crear y reutilizar funciones en Python.

## Actividad 1 - Crear una función

Crea una función llamada presentar que muestre un mensaje de bienvenida.

## Actividad 2 - Utilizar parámetros

Crea una función llamada saludar que reciba un nombre y muestre un saludo.

## Actividad 3 - Utilizar return

Crea una función llamada multiplicar que reciba dos números y devuelva su resultado.

Ejemplo:

    def multiplicar(numero_a, numero_b):
        return numero_a * numero_b

    resultado = multiplicar(4, 5)
    print(resultado)

Resultado esperado:

    20

## Actividad 4 - Reflexión

Explica con tus palabras:

- ¿Qué es una función?
- ¿Para qué sirven los parámetros?
- ¿Qué diferencia hay entre print y return?

## Aprendizaje

Las funciones permiten organizar programas, reutilizar código y resolver problemas mediante bloques independientes.

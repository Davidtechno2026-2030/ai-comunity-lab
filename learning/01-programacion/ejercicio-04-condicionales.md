# Ejercicio 04 - Condicionales

## Objetivo
Aprender a utilizar if, elif y else.

## Actividad

Crear un programa que compruebe si un número es positivo, negativo o cero.

## Ejemplo en Python

    numero = 5

    if numero > 0:
        print("Número positivo")
    elif numero < 0:
        print("Número negativo")
    else:
        print("El número es cero")

## Tu práctica

Prueba el programa con estos tres valores:

- 5
- -3
- 0

## Aprendizaje

Los condicionales permiten que un programa elija entre diferentes opciones.

# Lección 01 - ¿Qué es la programación?

## 1. Definición

La programación consiste en dar instrucciones a un ordenador para que realice determinadas tareas.

Estas instrucciones se escriben utilizando lenguajes de programación como Python, JavaScript o Java.

## 2. ¿Para qué sirve?

La programación permite:

- Crear páginas web.
- Desarrollar aplicaciones.
- Automatizar tareas.
- Crear videojuegos.
- Desarrollar herramientas de inteligencia artificial.

## 3. ¿Qué es un programa?

Un programa es un conjunto de instrucciones que un ordenador ejecuta para conseguir un objetivo.

## 4. Ejemplo cotidiano

Imagina que queremos preparar un vaso de agua:

1. Coger un vaso.
2. Abrir el grifo.
3. Llenar el vaso.
4. Cerrar el grifo.

En programación debemos organizar las instrucciones de forma clara y ordenada.

## 5. Conceptos importantes

- Programar: escribir instrucciones.
- Código: conjunto de instrucciones escritas en un lenguaje.
- Lenguaje de programación: sistema utilizado para comunicarnos con un ordenador.
- Programa: instrucciones que permiten realizar una tarea.

## 6. Ejercicio

Piensa en una tarea cotidiana y escribe cinco instrucciones ordenadas para realizarla.

## Resumen

Programar consiste en resolver problemas mediante instrucciones claras, ordenadas y precisas.

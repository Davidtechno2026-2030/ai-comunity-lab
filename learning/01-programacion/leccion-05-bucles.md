# Lección 05 - Bucles

## 1. ¿Qué es un bucle?

Un bucle permite repetir una o varias instrucciones varias veces sin tener que escribirlas de nuevo.

## 2. Bucle for

El bucle for permite repetir instrucciones un número determinado de veces.

## 3. Ejemplo con for

    for numero in range(5):
        print(numero)

Resultado:

    0
    1
    2
    3
    4

## 4. Bucle while

El bucle while repite instrucciones mientras se cumpla una condición.

## 5. Ejemplo con while

    contador = 1

    while contador <= 5:
        print(contador)
        contador = contador + 1

## 6. Diferencias

- for: se utiliza habitualmente cuando conocemos cuántas repeticiones necesitamos.
- while: se utiliza cuando queremos repetir mientras se cumpla una condición.

## Resumen

Los bucles permiten automatizar tareas repetitivas y reducir código.

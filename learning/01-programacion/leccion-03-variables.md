# Lección 03 - Variables y tipos de datos

## 1. ¿Qué es una variable?

Una variable es un espacio identificado por un nombre donde un programa guarda un dato.

## 2. Tipos de datos básicos en Python

- str: texto.
- int: números enteros.
- float: números decimales.
- bool: valores True o False.

## 3. Ejemplo en Python

    nombre = "David"
    edad = 16
    altura = 1.76
    estudia_programacion = True

    print(nombre)
    print(edad)
    print(altura)
    print(estudia_programacion)

## 4. Operaciones matemáticas

    precio = 450
    unidades = 2
    total = precio * unidades

    print(total)

## 5. Operadores básicos

- + Suma.
- - Resta.
- * Multiplicación.
- / División.

## Resumen

Las variables permiten almacenar información y utilizarla en las operaciones de un programa.

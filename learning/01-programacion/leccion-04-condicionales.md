# Lección 04 - Condicionales

## 1. ¿Qué es un condicional?

Un condicional permite que un programa tome decisiones dependiendo de si se cumple una condición.

## 2. La instrucción if

La instrucción if comprueba si una condición es verdadera.

## 3. La instrucción else

La instrucción else permite ejecutar otra alternativa cuando la condición no se cumple.

## 4. Ejemplo en Python

    temperatura = 35

    if temperatura > 30:
        print("Hace mucho calor")
    else:
        print("La temperatura es moderada")

## 5. Operadores de comparación

- == Igual que.
- != Distinto de.
- > Mayor que.
- < Menor que.
- >= Mayor o igual que.
- <= Menor o igual que.

## Resumen

Los condicionales permiten crear programas capaces de tomar decisiones.

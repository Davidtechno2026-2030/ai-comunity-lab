# Lección 02 - ¿Qué es un algoritmo?

## 1. Definición

Un algoritmo es un conjunto de pasos ordenados que permite resolver un problema o completar una tarea.

## 2. Ejemplo cotidiano

Problema: calcular cuánto dinero tenemos después de una compra.

1. Consultar el dinero disponible.
2. Consultar el precio del producto.
3. Restar el precio al dinero disponible.
4. Mostrar el resultado.

## 3. Características de un algoritmo

- Tiene un objetivo.
- Sigue un orden lógico.
- Sus instrucciones deben ser claras.
- Tiene un principio y un final.
- Debe terminar después de un número finito de pasos.

## 4. Algoritmos en programación

Los programas utilizan algoritmos para resolver problemas.

Un programador primero piensa cómo resolver el problema y después escribe el código.

## 5. Ejercicio

Diseña un algoritmo para calcular la suma de dos números.

Escribe los pasos necesarios desde que recibimos los números hasta que mostramos el resultado.

## Resumen

Un algoritmo es la planificación ordenada de una solución antes de convertirla en código.
